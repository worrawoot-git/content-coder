ThemeCoder วิเคราะห์เนื้อหา

ลงรหัสข้อมูลเชิงคุณภาพจากบทสัมภาษณ์ตาม Theme ที่กำหนด แสดงผลเป็นตารางและกราฟ พร้อมดาวน์โหลด Excel และ PNG

ขั้นที่ 1

ข้อมูลที่ต้องการวิเคราะห์

พิมพ์หรือวางข้อความได้ไม่จำกัดจำนวนคำ หากต้องการระบุผู้ให้สัมภาษณ์ ให้ขึ้นต้นบรรทัดด้วยชื่อตามด้วยเครื่องหมาย “:” เช่น ผู้ให้ข้อมูลคนที่ 1: ...

0 ตัวอักษร
คลิกเพื่อเลือกไฟล์ หรือลากไฟล์มาวางที่นี่
รองรับ .docx (Microsoft Word), .pdf และ .txt เลือกหลายไฟล์พร้อมกันได้ (กด Ctrl หรือ ⌘ ค้างไว้แล้วคลิก หรือกด Shift เพื่อเลือกเป็นช่วง) และกดเลือกเพิ่มทีหลังได้
ขั้นที่ 2

กำหนด Theme

ใส่ชื่อ Theme และคำสำคัญ (คั่นด้วยเครื่องหมายจุลภาค ,) ระบบจะจัดประโยคที่มีคำสำคัญเข้า Theme นั้น ถ้าไม่ใส่คำสำคัญ ระบบจะค้นหาจากชื่อ Theme

ขั้นที่ 3

ผลการวิเคราะห์

ตารางที่ 1 ประโยคที่จัดเข้าแต่ละ Theme

ตารางที่ 2 จำนวนประโยคจำแนกตาม Theme และผู้ให้สัมภาษณ์

ตารางที่ 3 การเกิดร่วมกันของ Theme (Co-occurrence Matrix)

ตารางที่ 4 คู่ Theme ที่เกิดร่วมกันและประโยคตัวอย่าง

แผนภูมิแท่ง: ความถี่ของแต่ละ Theme

แผนภูมิโดนัท: สัดส่วนของ Theme

แผนภูมิแท่งซ้อน: Theme ตามผู้ให้สัมภาษณ์

แผนภูมิเรดาร์: โปรไฟล์ของผู้ให้สัมภาษณ์

แผนภูมิเชิงขั้ว: จำนวนผู้ให้สัมภาษณ์ที่กล่าวถึง

แผนภูมิเส้น: การกระจายตัวตลอดเนื้อหา

แผนภูมิแท่งแนวนอน: คำที่พบบ่อย 15 อันดับ
